## CS-360 Mobile Architect and Programming
Nara Fog

Weigh Wise is an Android app that helps users track their weight and keep up with their personal goals. Users can create an account, log in, enter their weight, and access the Manage Alerts screen. I wanted to make the app simple and easy to use without adding too many unnecessary features.

When designing the app, I used navy blue and light blue to keep the screens looking consistent and clean. I made the buttons and text easy to understand so users could get around the app without getting confused. I think the design works well because it is straightforward and focuses on the main things users need.

I used Java and XML in Android Studio to build the app. I worked on one feature at a time, connected the buttons to the correct screens, and used a database helper for account creation and login. Breaking the project into smaller parts made it easier to work through and fix problems. I can use this same approach for future projects by building and testing each feature as I go.

I tested the app by checking the login, account creation, weight entry, and Manage Alerts features. When something did not work, I checked the code and layout files to find the problem. Testing was important because it helped me catch mistakes and make sure the app worked the way I wanted it to.

One challenge was getting the buttons and different screens to work together correctly. I had to pay attention to activity names, button IDs, and layout file names to fix errors. I think one of the parts I did well was connecting the Java code to the XML layouts and making the app's screens work together. Overall, this project helped me learn more about Android development, problem-solving, and creating an app that is useful and easy to navigate.
